# Taste — general preferences

## Workflow / Deploy
- Prefers Git-driven, upload-free deployment: push to a GitHub repo and let the host build & serve from source, rather than uploading files to a hosting panel (FTP/File Manager) or doing a local build. Confidence: 0.75
- Prefers Vercel as the deployment/hosting platform. Confidence: 0.6

## Communication
- Wants explicit, step-by-step deployment runbooks/processes ("give me the process / guideline how to deploy") rather than high-level summaries. Confidence: 0.7
